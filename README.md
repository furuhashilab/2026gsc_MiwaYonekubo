# 猫バスはどこに停まるのか―OpenStreetMapによるジブリ聖地情報のオープンデータ化

**Where Does the Catbus Stop? — Open Data of Studio Ghibli Pilgrimage Sites Using OpenStreetMap**

著者：米久保美和

最終更新：2026年11月

## Abstract

スタジオジブリ作品の舞台モデル地（聖地）を訪れる「聖地巡礼」は、訪日観光の新たな動機として注目されている。
しかし現状、聖地情報はファンコミュニティによる口コミや非公式サイトに散在しており、地図データとしての構造化・オープン化が進んでいない。
本研究では、世界最大のオープン地図プラットフォームである OpenStreetMap（OSM）を用いて、ジブリ作品の公認舞台モデル地を体系的にマッピングし、誰でも編集・活用できるオープンデータとして整備する手法を提案・実装する。

---

## 1. Introduction

### 背景

「となりのトトロ」の猫バスのバス停、「千と千尋の神隠し」の油屋のモデルとなった建物、「魔女の宅急便」のコリコの町のモデルになった街並み。これらスタジオジブリ作品の舞台モデル地は、国内外のファンが実際に訪れる「聖地」として広く知られている。

こうした「アニメ聖地巡礼」は近年、訪日外国人を含む観光行動として急速に拡大しており、地域経済への貢献も報告されている。
一方で、聖地情報の多くはファンによる非公式な口コミや、更新・検証が困難な個人ブログに依存しており、地図データとして構造化・オープン化された事例は極めて少ない。

### 問題提起

> 「猫バスはどこに停まるのか」――この素朴な疑問を、現在の地図サービスに入力しても正確な答えは返ってこない。

Google マップにも、既存の観光アプリにも、ジブリ聖地の情報は断片的にしか存在しない。ましてや、誰でも編集・検証・再利用できる形式での整備はほぼなされていない。

### 研究目的

本研究は以下の2点を目的とする。

1. スタジオジブリ作品の公認舞台モデル地を対象に、OSM上での聖地情報タグスキームを設計・提案する。
2. 設計したタグスキームに基づき、実際にOSMへのマッピングを実施し、オープンデータとしての有効性を検証する。

### 研究の新規性

- 聖地情報を「ファンの口コミ」ではなく、オープンかつ検証可能な地図データとして構造化した初めての体系的試み
- OSMタグスキームとして提案することで、ジブリ以外の作品・他国のコンテンツ聖地にも転用可能な汎用フレームワークを提供する

---

## 2. Methods

### 対象作品・地点の選定

スタジオジブリが公式に舞台モデルを認めている、または公式サイト・関連書籍で言及されている地点を対象とする。具体的には以下を参照する。

- スタジオジブリ公式サイトおよびジブリ美術館の公開情報
- 「ジブリの立体建造物展」等の公式展示資料
- 国内各自治体が公認しているジブリ関連観光スポット

### OSMタグスキームの設計

既存の OSM タグ体系（`tourism`、`historic`、`amenity` 等）を参照しつつ、コンテンツ聖地に特化したタグスキームを設計する。提案タグの例を以下に示す。

```
content_tourism = pilgrimage_site
content_tourism:type = anime / film / novel
content_tourism:work = となりのトトロ
content_tourism:creator = スタジオジブリ
content_tourism:official = yes / fan_consensus
```

### マッピング作業

JOSM（Java OpenStreetMap Editor）を用いて、選定した地点を OSM に登録・タグ付けする。作業記録は本リポジトリの Issues に逐次記録する。
