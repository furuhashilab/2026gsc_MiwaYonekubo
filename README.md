# ネコバスはどこに停まるのか―OpenStreetMapによるジブリ聖地情報の公式化

**Where Does the Catbus Stop? — Open Data of Studio Ghibli Pilgrimage Sites Using OpenStreetMap**

著者：米久保美和

ライセンス:©FuruhashiLaboratory/米久保美和, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)  

最終更新：2026年11月

## Abstract

構想発表での内容から絞り込み、スタジオジブリの名作「となりのトトロ」を使用した聖地巡礼マップを、ネコバスに乗車した気分で巡る、ストーリーテリングマップとして作成する。（構想発表での内容は[Archive](Archive)に記載)

スタジオジブリ作品「となりのトトロ」の舞台モデル地（聖地）を訪れる「聖地巡礼」は、訪日観光の新たな動機として注目されている。しかし現状、聖地情報はファンコミュニティによる口コミや非公式サイトに散在しており、地図データとしての構造化・オープン化が進んでいない。本研究では、世界最大のオープン地図プラットフォームである OpenStreetMap（OSM）を用いて、公式に認定された「となりのトトロ」の舞台モデル地をネコバスの「停留所」として体系的にマッピングし、誰でも編集・活用できる公式の情報として整備する手法を提案・実装する。

---

## 1. Introduction

### 背景

「となりのトトロ」のネコバスのバス停、七国山病院の見える丘、トトロが宿る里山の雑木林――これらスタジオジブリ作品の舞台モデル地は、国内外のファンが実際に訪れる「聖地」として広く知られている。

こうした「アニメ聖地巡礼」は近年、訪日外国人を含む観光行動として急速に拡大しており、地域経済への貢献も報告されている。一方で、聖地情報の多くはファンによる非公式な口コミや、更新・検証が困難な個人ブログに依存しており、地図データとして構造化・オープン化された事例は極めて少ない。

### 問題提起

> 「ネコバスはどこに停まるのか」――この素朴な疑問を、現在の地図サービスに入力しても正確な答えは返ってこない。

Google マップにも、既存の観光アプリにも、ジブリ聖地の情報は断片的にしか存在しない。ましてや、誰でも編集・検証・再利用できる形式での整備はほぼなされていない。

### 研究目的

本研究は以下の2点を目的とする。

1. 「となりのトトロ」の公認舞台モデル地を対象に、OSM上での聖地情報タグスキームを設計・提案する。
2. 設計したタグスキームに基づき、実際にOSMへのマッピングを実施し、オープンデータとしての有効性を検証する。

### 研究の新規性

- 聖地情報を「ファンの口コミ」ではなく、オープンかつ検証可能な地図データとして構造化した初めての体系的試み
- OSMタグスキームとして提案することで、ジブリ以外の作品・他国のコンテンツ聖地にも転用可能な汎用フレームワークを提供する
- 「ネコバス停留所」という物語的なメタファーを用いて、観光体験としての聖地巡礼と地図データの整備を統合する

## 2. Methods

### 対象作品・地点の選定基準

スタジオジブリが公式に舞台モデルを認めている、または行政・公益財団法人が公認している地点のみを対象とする。  
具体的には以下の基準を適用する。

- スタジオジブリ公式サイトおよびジブリ関連書籍で言及されている地点
- 地方自治体が公認しているジブリ関連観光スポット（案内板・観光マップへの掲載）
- 公益財団法人等の公的機関が認定している関連地

**ファンによる「有力モデル地」は対象外とし、公的に認定されたもののみを採用する。**

### マッピング済み公認地点（となりのトトロ）

| 停留所番号 | 地点名 | 所在地 | 公認主体 |
|-----------|--------|--------|---------|
| 第1停 | 狭山丘陵（トトロの森） | 埼玉県所沢市・東京都東村山市 | 公益財団法人トトロのふるさと基金 |
| 第2停 | 八国山緑地（七国山病院モデル） | 東京都東村山市 | 東村山市（案内板設置・観光資源認定） |
| 第3停 | 松郷バス停 | 埼玉県所沢市 | 所沢市（観光マップ掲載・公認スポット） |
| 第4停 | 三ヶ島地区の農村風景 | 埼玉県所沢市三ヶ島 | 所沢市（「となりのトトロのまち」公式プロモーション） |


➡️今回はこの４ヶ所のみでマッピングを行ったが、ゼミ論の最終発表までに、より多くの場所をマッピングする予定。

### 現時点で確定している追加のマッピング地点

クロスケの家（埼玉県所沢市三ヶ島）— 公益財団法人トトロのふるさと基金が管理する古民家。保全活動の公式拠点で、映画に登場するサツキとメイの家の雰囲気に近い農村建築。見学可。
淵の森緑地（東京都東村山市・所沢市またがり）— 東村山市が公式案内で「宮崎監督が散策しながら作品のアイデアを練った場所」と紹介している森。雑木林のシーンのベース。
所沢駅東口トトロモニュメント（埼玉県所沢市）— 所沢市が設置した公式モニュメント。大トトロ・サツキ・メイの像。特定シーンではなく「となりのトトロのまち所沢」の象徴として行政が公式に位置づけ。
新山手病院（東京都東村山市）— 七国山病院の直接モデルとされる現役病院。東村山市の資料でも言及あり（現役医療機関のため外観のみ）。サツキとメイのお母さんが入院するシーン。


また、先日の１or１ミーティングで提案して頂いた、メイやサツキが辿った道のりを巡る地図の作成、またはネコバスで一度提示された場所について深掘りし、その場所もマッピングする。

### OSMタグスキームの設計

既存の OSM タグ体系（`tourism`、`historic`、`amenity` 等）を参照しつつ、コンテンツ聖地に特化したタグスキームを設計する。提案タグの例を以下に示す。

```
content_tourism = pilgrimage_site
content_tourism:type = anime
content_tourism:work = となりのトトロ
content_tourism:creator = スタジオジブリ
content_tourism:official = yes
content_tourism:stop_name = ネコバス停留所 第1停
source:certification = 公益財団法人トトロのふるさと基金
```

### マッピング作業

JOSM（Java OpenStreetMap Editor）を用いて、選定した地点を OSM に登録・タグ付けする。作業記録は本リポジトリの Issues に逐次記録する。

## 3. 先行研究

本研究に関連する先行研究を「①アニメ聖地巡礼・コンテンツツーリズム研究」「②OpenStreetMap・ボランタリー地理情報（VGI）研究」「③文化資源のOSMタグ付け研究」の3つの観点から整理する。

### 1. アニメ聖地巡礼・コンテンツツーリズム研究

**岡本健ほか（2021）「全国アニメ聖地巡礼地アンケート調査による巡礼地域への影響・効果の研究」**

全国の聖地を対象に、訪問者数・経済効果・地域への影響を定量調査した研究。聖地情報の発信が公式サイトではなく非公式のファンサイトやSNSに依存していることが課題として示された。本研究はこの「非公式情報への依存」という課題に対し、OSMによるオープンデータ化という形で応答する。

> 岡本健ほか. (2021). 全国アニメ聖地巡礼地アンケート調査による巡礼地域への影響・効果の研究. 島根大学学術情報リポジトリ. https://ir.lib.shimane-u.ac.jp/54786/files/12680

**神田孝治（2015）「コンテンツツーリズム研究の動向と課題」**

コンテンツツーリズム研究を体系的にレビューした論文。既存研究が訪問動機・心理分析に偏っており、聖地情報のインフラ整備という観点の研究が不足していることを指摘している。本研究はこの空白に直接アプローチする。

> 神田孝治. (2015). コンテンツツーリズム研究の動向と課題. 立命館大学学術成果リポジトリ. https://ritsumei.repo.nii.ac.jp/record/11976/files/51216002.pdf

### 2. OpenStreetMap・VGI研究

**Goodchild, M. F.（2007）"Citizens as sensors: The world of volunteered geography"**

市民参加型地理情報生成（VGI）の概念を提唱した基礎的論文。GPS端末やウェブの普及により、市民が地理情報の生産者になりうることを示した。OSMはこの概念の代表的な実装例であり、本研究がOSMを採用する理論的根拠となる。

> Goodchild, M. F. (2007). Citizens as sensors: The world of volunteered geography. *GeoJournal*, *69*(4), 211–221. https://doi.org/10.1007/s10708-007-9111-y

**Haklay, M.（2010）"How good is volunteered geographical information?"**

OSMと英国政府公式地図データを比較し、主要道路において平均誤差約6mという実用水準の精度を確認した実証研究。OSMデータの品質的信頼性を裏付ける知見として参照する。一方、マイナーな地物ではデータが薄くなるという指摘は本研究の限界としても認識する。

> Haklay, M. (2010). How good is volunteered geographical information? *Environment and Planning B*, *37*(4), 682–703. https://doi.org/10.1068/b35097

### 3. 文化資源のOSMタグ付け研究

**Brovelli, M. A. et al.（2025）"OpenStreetMap for Cultural Heritage Documentation and Tourism"**

文化遺産スポットをOSMに記録するためのタグスキーム設計と実装事例を報告した最新研究。既存タグの限界を整理し、公式認定の有無・属性の出典明示などを含む拡張タグの設計プロセスを詳述している。本研究のタグスキーム設計の直接的な参照モデルとする。

> Brovelli, M. A. et al. (2025). OpenStreetMap for cultural heritage documentation and tourism. *ISPRS Archives*, *XLVIII-M-9-2025*, 525–530. https://isprs-archives.copernicus.org/articles/XLVIII-M-9-2025/525/2025/

### 本研究の位置づけ

| 観点 | 先行研究 | 本研究 |
|------|---------|--------|
| 聖地情報の整備 | 非公式サイト・口コミ中心 | OSMによるオープンデータ化 |
| OSMの対象 | 道路・建物・文化遺産 | アニメ・映画聖地（新規） |
| 実装の有無 | 一部あり | あり（試作マップ含む） |

## 4. 著作権・知的財産権の課題と対応方針

### 課題

ジブリ作品の聖地情報をOSMに登録するにあたり、以下の著作権・権利関係の問題が存在する。

**（1）作品名・キャラクター名の使用**  
「となりのトトロ」「トトロ」等の名称はスタジオジブリが著作権・商標権を保有する。OSMのタグ値としてこれらを記載することは、地理情報の事実記述であり、商業的な使用には当たらないと解釈できるが、慎重な運用が必要。

**（2）公認・非公認の混同**  
「有力モデル地」として広くファンに知られる地点をOSMに記載すると、公式認定であるかのように誤解される恐れがある。

**（3）写真・画像の使用**  
マップ上に写真を掲載する場合、撮影者の著作権が発生する。ジブリ作品のスクリーンショット等はスタジオジブリの著作権物であり、無断掲載は不可。

### 対応方針

| 課題 | 対応方針 |
|------|---------|
| 作品名・キャラクター名の使用 | OSMタグは事実の記述であり、`source:certification` タグで公認主体を明示する。|
| 公認・非公認の混同 | タグ値 `content_tourism:official = yes / fan_consensus` で明確に区別し、本研究では `yes`（公認）のみを採用 |
| 写真・画像の使用 | マップ上の画像はCC BY/CC0ライセンスの写真だけでなく、無料で配布されているスタジオジブリサイトに掲載されている画像、または現地写真は自ら撮影したものを使用する |
| OSMデータのライセンス | OSMはODbL（Open Database License）。タグ付けしたデータはこのライセンスのもとで公開され、再利用可能 |

➡️Wikipediaで使用されているキャラクター名はOSMでも使用可。
OSMデータにWikipediaのタグを紐付ければ、説明を入れなくても使用可能なことがわかった。

### スタジオジブリの公式方針との整合性

スタジオジブリは2020年から公式スチール画像を著作権表示条件付きで無償提供しており、非商業的な文化的活動に対する親和性を示している（ただし映像素材は対象外）。
本研究は非商業・学術目的であり、公認地点のみを対象とすることで権利侵害のリスクを最小化する。
