# 日本映画のロケ地巡礼マップアプリの開発
本研究は卒論時まで継続的に行う研究として最終的にはアプリケーション、もしくはWebサイトの完成を目標とする。

## 概要（Abstract）
対象テーマ：日本映画を軸とした国内コンテンツツーリズムのアクセシビリティ向上に関する研究

方針：本研究は現段階においてアイデアの構想・設計段階にあるため、今後は「プロトタイプの早期実装」「ユーザビリティの検証」「データ検証」という３つのフェーズを段階的に踏むことで、客観的な成果と結論を導き出す。

主要な動き：映画のロケ地データを集約し、誰もが直感的に利用できる「聖地巡礼マップWebアプリケーション」の試作と実装

アプローチ：アプリケーション開発と観光行動の分析は、システム設計（エンジニアリング的アプローチ）とフィールドワーク（社会科学的アプローチ）の両面を必要とするため、明確な目標設定をしながら進める。

## 導入（Introduction）
本研究では、コンテンツツーリズムをテーマとし、日本映画で使用された国内のロケ地を巡礼できるWebアプリケーションの開発に取り組む。

研究背景：アニメやドラマの聖地巡礼に関する先行研究や観光振興事例は豊富である一方、「日本映画」のロケ地に特化した観光動向や情報アクセスの仕組みに関する研究は少ない。
また、日本映画作品は地域の日常的な風景を情緒的に切り取るため、公開後の観光誘致において高いポテンシャルを秘めている。

## 今後の研究目標（Milestones）
 成果を生み出すために、以下の3つの具体的な目標を設定する。
 
1. 「探す手間」をなくすデータの一元化：ネット上にバラバラに点在している日本映画のロケ地情報やアクセス方法を体系的に収集し、アプリケーションから一目でわかる状態のデータベースを構築する。

2. 誰でもすぐに使えるアクセシビリティの追求：特別な操作や複雑な操作を一切不要とし、現在地からロケ地までのルート案内が起動するWebアプリケーションを設計・実装すること。

3. 観光業に対する明確な効果の検証：実際に試作したアプリを用いた検証実験を通じて、「観光客のフットワークが軽くなったか」「聖地巡礼によって未上陸地への旅が可能になったか」「どれくらい移動しやすくなったか」など、アンケートのデータをもとに証明をする。

11月下旬：中間発表

1月上旬〜中旬：データの整理と考察

得られた結果をもとに、最終発表に向けたスライドや論文の原稿を執筆する。


第4フェーズ：最終発表（2月上旬~中旬）

2月上旬：最終発表

これまでの研究成果（アプリの試作と、それを通じた考察）を全体に向けて発表する。

### 2月以降の予定

卒業論文・その先を見据えた「アプリケーションの応用・改善プラン」

2月の発表や卒業論文で終わりにするのではなく、「その先にアプリをどう進化させるか」という発展的な展望を以下のように想定する。

1. ユーザー参加型（投稿・口コミ）機能の追加

運営側がデータを登録するだけでなく、訪れたファン自身が「新しいロケ地を発見して追加できる」機能や、現場の写真・感想を共有できる仕組みの実装。

2. 周辺観光スポット（グルメ・宿）の提案

映画のロケ地だけでなく、その近くにあるおすすめの飲食店や宿泊施設を連動させ、ロケ地巡りを起点とした「地域の消費活動（経済波及効果）」をさらに高める機能の拡張。

3. 多言語対応とインバウンド（海外観光客）への展開

訪日外国人のロケ地巡り（聖地巡礼）需要を見据え、英語やアジア圏の言語に対応したUI切り替え機能の導入。

4. 自治体や映画製作委員会との連携モデルの構築

個人の研究レベルから一歩進め、実際のロケ地誘致を行っている自治体や映画の公式プロモーションと連携し、公式マップアプリとして運用できるような実用性の検証。


## 予想されるリスクや課題と対策

### リスク1：開発の遅延対策
→最初から完璧な機能を盛り込まず、まずは地図とピン立て機能のみの最小限（MVP）から公開し、段階的にアップデートする今後に向けた開発的な手法をとる。

### リスク2：被験者の確保難対策
→まずはゼミのメンバーや学内を対象にした手軽なテスト環境を早期に構築し、テストをお願いする。

### 課題1：著作権及び権利関係のクリアライセンス問題
映画の劇中画像やセリフ、公式ロゴなどをマップアプリ上で利用する際、著作権やパブリシティ権観点から厳格な制約が生じる点。

→商業利用や本格的な自治体連携を見据えた場合、著作権者・製作者委員会との法的調整や許可プロセスの標準化が不可欠であるという法制面の課題を解決する必要がある。

### 課題2：データメンテナンスの持続可能性
ロケ地となった店舗の閉店や移転、または風景の改変など、時間の経過に伴う情報の変化にいかに対応するかという運用の負担

→ユーザーからの情報提供機能（Crowdsourcing）機能などを加えて、より新鮮で明確な情報を集める。

## この研究から予想される成果
アクセシビリティ向上と観光行動の相関データの証明。

このアプリケーションを生み出すことで、「情報を分かりやすく提供することが、どれだけ観光客の行動範囲（回遊性）を広げるか」という仮説を、実際のユーザーテストやデータによって実証できる。また、日本国内での旅行を行う国民も増えると、観光による経済効果も期待できる。

あくまでも、外国人観光客のみに向けたアプリケーションではなく、日本の魅力を日本国民を中心とした全世界の人々に広げるアプリケーションの作成。
